# tgcli 8 remediation coverage

The [original audit](../audits/2026-11-20/README.md) describes the 7.0.1 baseline. The [historical flow catalog](v8-usage-flows.md) derives its fixtures from 1,224 available local Codex rollouts, including 81 command-bearing rollouts. The [supplementary scan](v8-history-coverage.md) records archive overlap and device coverage limits. This page maps those requirements to v8 code and named tests. [Release validation](v8-release-validation.md) records the executions and remaining checks.

Tests below run actual production code with synthetic TDLib responses, local files, or isolated subprocesses. The table calls out places where a component test covers only part of the original scenario. Repository tests use synthetic identifiers and generated fixtures. Where a controlled Telegram run corroborates a scenario, the [live acceptance record](v8-release-validation.md#live-telegram-acceptance) identifies its scope.
